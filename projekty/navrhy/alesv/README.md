# ALEŠ‑V — redizajn homepage a stručný report

Balík obsahuje dve úplne oddelené stránky:

- `report.html` — stručné profesionálne zhodnotenie pôvodného webu;
- `index.html` — funkčný návrh novej homepage.

## Spustenie

Otvorte `report.html` alebo `index.html` v modernom prehliadači. Stránky nevyžadujú framework, build proces ani internetové pripojenie.

## Assets

Použité firemné podklady boli stiahnuté z verejne dostupného webu ALEŠ‑V:

- `assets/images/logo.png` — https://ales-v.sk/wp-content/uploads/2019/11/ales-v-logo-75.png
- `assets/images/autodoprava.jpg` — https://ales-v.sk/wp-content/uploads/2019/11/autodoprava.jpg
- `assets/images/cesta.jpg` — https://ales-v.sk/wp-content/uploads/2019/11/ALES-V-cesta.jpg

Piktogramy v `assets/icons/` pochádzajú z otvorenej knižnice [Lucide](https://lucide.dev/) a sú použité podľa licencie ISC.

- `assets/images/beewoy-logo.svg` — oficiálne logo autora reportu z https://beewoy.sk/logo.svg

Pred produkčným nasadením odporúčame potvrdiť právo na ich ďalšie používanie a prípadne dodať kvalitnejšie originály. Priečinky `assets/icons/` a `assets/fonts/` sú zámerne prázdne; návrh používa CSS a systémové fonty.

## Formulár

Statický formulár v `index.html` otvorí predvolený e‑mailový program s predvyplnenou správou na `info@ales-v.sk`. Pri produkčnom nasadení ho odporúčame napojiť na overenú formulárovú službu alebo backend so súhlasom so spracovaním osobných údajov, ochranou proti spamu a potvrdením úspešného odoslania.

## Údaje na potvrdenie alebo doplnenie

- aktuálnosť všetkých služieb a tvrdenia o dostupnosti mimo pracovných hodín;
- presný proces nacenenia a obvyklý čas odpovede;
- podmienky ADR, chladiarenskej a nadrozmernej prepravy;
- reálne referencie, partnerstvá, oprávnenia alebo realizácie;
- aktuálnosť adresy, telefónu, e‑mailu a firemných údajov;
- zásady ochrany osobných údajov a produkčné spracovanie formulára.

## Zdroj analýzy

Verejne dostupná homepage https://ales-v.sk/ skontrolovaná 6. augusta 2026. Hodnotenie v reporte je orientačné a nie je certifikovaným auditom prístupnosti ani úplným technickým auditom.
