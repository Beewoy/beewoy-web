# Plastoplan SK — koncept redizajnu homepage

Samostatná statická ukážka homepage pre PLASTOPLAN SK, s.r.o. Všetky štýly a skripty sú vložené priamo v `index.html`; priečinok `assets/` obsahuje lokálne logo a fotografie prevzaté z pôvodného verejného webu spoločnosti.

## Spustenie

Otvorte `index.html` v modernom webovom prehliadači. Internetové pripojenie nie je potrebné na zobrazenie stránky; externé odkazy v pätičke smerujú na pôvodný web Plastoplan.

## Formulár

Ide o statickú ukážku bez serverového spracovania. Po úspešnej kontrole povinných polí otvorí formulár predvolený e-mailový program a pripraví správu pre `plastoplan@plastoplan.sk`. Pri nasadení na produkciu sa odporúča formulár napojiť na bezpečný backend, doplniť antispam ochranu a serverové potvrdenie odoslania.
