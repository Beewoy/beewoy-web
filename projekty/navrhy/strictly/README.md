# STRICTLY — statický web

Hotový web sa nachádza v tomto priečinku a nevyžaduje build ani externé balíčky.

## Spustenie

Otvorte `index.html` v prehliadači alebo celý priečinok naservírujte cez ľubovoľný statický hosting.

## Súbory

- `index.html` — hlavná stránka
- `ochrana-osobnych-udajov.html` — pracovný návrh zásad ochrany osobných údajov
- `pravne-informacie.html` — firemné a právne údaje
- `assets/styles.css` — celý responzívny dizajn
- `assets/site.js` — mobilné menu, animácie, formulár a mapa
- `assets/images/` — optimalizované lokálne obrazové podklady

## Pred ostrým nasadením

1. Overiť čísla 15+ rokov, 500+ zákazníkov a 780+ projektov.
2. Nahradiť ukážkové vizuály fotografiami reálnych realizácií, ak sú dostupné.
3. Nechať skontrolovať právne texty.
4. Prepojiť formulár na reálny formulárový alebo CRM endpoint, ak nemá používať e-mailovú aplikáciu návštevníka.
5. Po nasadení skontrolovať canonical a Open Graph URL.
