# IN-DOM – návrh novej homepage

Statická ukážka redizajnu úvodnej stránky, vytvorená na základe analýzy verejného webu IN-DOM.

## Spustenie

Otvorte `index.html` v modernom prehliadači. Stránka funguje bez frameworku, build procesu a internetového pripojenia. CSS aj JavaScript sú vložené priamo v HTML.

## Obsah balíka

- `index.html` – kompletný responzívny návrh homepage
- `assets/images/in-dom-logo.jpg` – pôvodné logo IN-DOM
- lokálne produktové fotografie a fotografie realizácií

Súbor `report.html` a logo Beewoy zostávajú v pracovnom výstupe kvôli predchádzajúcej časti zadania, ale nie sú súčasťou homepage ani ZIP balíka homepage.

## Formulár

Formulár je zámerne statický a nič neodosiela. Pred nasadením treba:

1. zvoliť formulárovú službu alebo vlastný backend,
2. nahradiť `action="#"` cieľovou adresou,
3. upraviť obsluhu udalosti `submit` na konci `index.html`,
4. doplniť informácie o spracovaní osobných údajov a súhlas podľa reálneho procesu firmy,
5. vykonať test odosielania, chybových stavov a doručovania.

## Overenie pred nasadením

- Potvrdiť presné adresy a otváracie hodiny oboch predajní.
- Potvrdiť aktuálnosť ponuky, výrobcov a rozsah poradenstva.
- Doplniť iba overené Google profily a recenzie, ak ich chce firma použiť.
- Opraviť alebo doplniť Instagram až po potvrdení platného profilu.
- Vykonať úplný test prístupnosti, výkonu, SEO a formulára na cieľovom hostingu.

Návrh netvrdí, že je certifikovaný alebo úplne auditovaný.
