# Boulanger & Patissiere - prémiový redizajn

Samostatný slovenský prototyp domovskej stránky bez build procesu, pripravený podľa dodaného vizuálneho návrhu.

## Vizuálny smer

- Svetlá krémová paleta, tmavozelená typografia a malinový akcent.
- Editorial display typografia doplnená o Manrope pre navigáciu a bežné texty.
- Kompozícia podľa referencie: hero, hodnoty, ponuka, príbeh, torty na mieru, Instagram, návšteva a päta.
- Existujúce verejné fotografie značky sú použité v produktových a obsahových sekciách.
- Hero fotografia vznikla špeciálne pre tento redizajn pomocou vstavaného generovania obrázkov.
