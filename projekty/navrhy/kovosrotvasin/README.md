# KOVOŠROT VAŠIN – koncept redizajnu homepage

Statická responzívna ukážka novej domovskej stránky. Nevyžaduje build proces ani externé knižnice; stačí otvoriť `index.html` v prehliadači.

Vizuál používa bielu, svetlomodrú a tmavomodrú paletu nadväzujúcu na pôvodnú farebnosť webu. Zelená nie je použitá ako súčasť novej identity.

## Obsah balíka

- `index.html` – všetko HTML, CSS a JavaScript
- `assets/logo.png` – pôvodné firemné logo
- `assets/hero.jpg` – pôvodný banner
- `assets/prevadzka-1.jpg`, `assets/prevadzka-2.jpg` – fotografie z pôvodnej fotogalérie

## Formulár

Formulár zámerne nič neodosiela. Pred publikovaním treba jeho obsluhu pripojiť k zvolenému backendu alebo formulárovej službe a doplniť súhlas so spracovaním osobných údajov podľa reálneho riešenia.

## Otvorené body pred publikovaním

- potvrdiť aktuálnosť telefónov, otváracích hodín, adresy a rozsahu služieb;
- doplniť aktuálny cenník alebo vysvetlenie spôsobu stanovenia výkupných cien;
- rozhodnúť, či má homepage uvádzať aj prevádzku Gbely a jej samostatné kontakty/hodiny (pôvodná kontaktná stránka uvádza adresu iba v Čároch, rozhodnutia však spomínajú aj Gbely);
- pridať priame odkazy na aktuálne rozhodnutia a zásady ochrany osobných údajov;
- pripojiť formulár, analytiku a meranie telefonických konverzií;
- potvrdiť práva na ďalšie použitie fotografií mimo pôvodného webu a doplniť novšie profesionálne fotografie, ak sú dostupné.

## Poznámka k implementácii

Navigácia, mobilné menu, odkazy `tel:`/`mailto:`, natívna validácia formulára, focus stavy, redukcia pohybu a responzívne rozloženie sú zahrnuté. Stránka neobsahuje ďalšie HTML súbory ani externé runtime závislosti.
