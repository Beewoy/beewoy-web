# PODHORA s.r.o. – návrh redizajnu homepage

Statická ukážka modernej domovskej stránky založená na obsahu verejne dostupnom na `stavebnepracepodhora.sk` dňa 5. 8. 2026.

## Spustenie

Otvorte `index.html` v modernom prehliadači. Stránka nevyžaduje inštaláciu ani zostavenie. Ikony sa načítavajú z CDN knižnice Font Awesome, preto ich zobrazenie vyžaduje internetové pripojenie.

## Obsah balíka

- `index.html` – kompletná stránka, CSS a JavaScript sú vložené inline
- `assets/` – originálne logo a fotografie z existujúceho webu firmy
- `README.md` – tento dokument
