**Content:** Bakery storefront, interior, or fresh bread/pastries

## How to add images

1. Download from https://nasapekaren.sk/wp-content/uploads/ (use browser)
2. Resize to appropriate dimensions if needed
3. Save with names above (`img0.jpg`, `img1.jpg`, etc.)
4. Place in this `assets/` folder
5. Commit and push
