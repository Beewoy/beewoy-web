# Vainex — redizajn homepage a stručný report

Balík obsahuje dve úplne oddelené statické stránky:

- `index.html` — návrh novej homepage Vainex bez prvkov Beewoy
- `report.html` — stručné zhodnotenie pôvodného webu vo vizuálnej identite Beewoy
- `assets/images/` — lokálne uložené obrázky a logá

## Spustenie

Otvorte `report.html` alebo `index.html` priamo v modernom prehliadači. Nie je potrebná inštalácia ani build proces.

## Poznámky

- Obsah návrhu vychádza z verejne dostupných informácií na `vainex.sk` skontrolovaných 10. augusta 2026.
- Uvedené čísla realizácií, služby a kontakty pochádzajú z pôvodného webu Vainex.
- Formulár v návrhu používa `mailto:` ako demonštračné riešenie; pri produkčnom nasadení ho treba napojiť na reálny formulárový endpoint.
- Obrázky Vainex a logo Beewoy sú uložené lokálne, aby stránky neboli závislé od hotlinkingu.
