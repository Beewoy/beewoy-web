FAQ

Časté otázky k cenám

Aký je rozdiel medzi Start a Profi?
Start je web + starostlivosť. Profi pridáva aktívny rast: Google profil, recenzie a socials.
Čo znamená Individual?
Web na mieru podľa rozsahu — vhodné pri špecifických požiadavkách. Cenu dohodneme na konzultácii.
Je v cenách viazanosť?
Nie. Žiadna viazanosť. Vhodný plán prejdeme na nezáväznej konzultácii.
Ako dlho trvá dodávka?
Pri pripravených podkladoch vieme dodať výrazne rýchlejšie — orientačne aj do 48 hodín od schválenia zadania. Presný termín potvrdíme podľa rozsahu.
